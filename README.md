# Beehadang's portfolio

เว็บแอปบันทึกพอร์ตการลงทุนส่วนตัว ข้อมูลทั้งหมดเก็บในเครื่อง (IndexedDB ของเบราว์เซอร์) ไม่มีเซิร์ฟเวอร์

## ระยะที่ 1 มีอะไรบ้าง
- บันทึกซื้อ/ขาย/ปันผล/ดอกเบี้ย/ค่าธรรมเนียม แยกบัญชี (Dime, Bitkub, Bitazza, Binance, ธนาคาร)
- ราคาอัตโนมัติ: คริปโตจาก CoinGecko, ค่าเงิน USD/THB จาก open.er-api, หุ้นสหรัฐจาก Finnhub (ต้องใส่คีย์ฟรี), ทองใส่ราคาเอง
- กำไร/ขาดทุนต่อตัวเป็นบาท แยกผลจากค่าเงิน, XIRR ทั้งพอร์ตและรายตัว
- สัดส่วนเทียบพอร์ตเป้าหมาย 70/15/5/10 แจ้งเตือน rebalance และการกระจุกตัว
- แนะนำว่าเงิน DCA เดือนนี้ควรลงกลุ่มไหน, แผน DCA พร้อมเตือนเมื่อถึงรอบ
- บันทึกเหตุผลการลงทุน วันทบทวน และหน้าทบทวน
- เป้าเกษียณ (อายุ 28 → 55, ปันผล 50,000 บาท/เดือน)
- สำรอง/กู้คืนข้อมูลเป็นไฟล์เข้ารหัส (AES-GCM + รหัสผ่าน)

## ติดตั้งบนมือถือ
1. เปิดลิงก์ GitHub Pages ของแอปใน Safari (iPhone)
2. กดปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
3. เปิดจากไอคอนบนหน้าจอ ใช้งานแบบออฟไลน์ได้ (ราคาอัปเดตเมื่อมีเน็ต)

## ข้อควรรู้
- ลบแอปหรือล้างข้อมูล Safari = ข้อมูลหาย ให้กด "สำรองข้อมูล" ในหน้าตั้งค่าแล้วเก็บไฟล์ไว้ใน iCloud Drive เป็นประจำ
- ต้นทุนคิดแบบถัวเฉลี่ย แปลงเป็นบาทด้วยอัตราแลกเปลี่ยน ณ วันที่ทำรายการ
